# Code of conduct

lastcall follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:
- be respectful and assume good faith;
- keep discussions about the work;
- welcome people whatever their experience.

Harassment, insults and personal attacks are not accepted anywhere the project lives: issues, pull requests,
reviews and commits.

To report a problem privately, use the repository's private report
([Security › Report a vulnerability](https://github.com/ne0x86/lastcall/security/advisories/new)) and say that it
is about conduct. The maintainer will read it and reply in confidence.
